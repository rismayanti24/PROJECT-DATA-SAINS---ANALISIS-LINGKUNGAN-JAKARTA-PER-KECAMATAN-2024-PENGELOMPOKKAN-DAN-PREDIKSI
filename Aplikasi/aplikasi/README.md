# Aplikasi Analisis Lingkungan Jakarta 2024

Cara menjalankan di laptop:
1. Pasang Python 3.10 atau lebih baru.
2. Buka terminal di folder ini, lalu:
   pip install -r requirements.txt
   streamlit run app.py
3. Browser terbuka otomatis (alamat http://localhost:8501).

Cara deploy gratis (opsional):
1. Unggah folder ini ke repo GitHub (app.py, requirements.txt, folder data).
2. Buka share.streamlit.io, login GitHub, pilih repo, file utama app.py, klik Deploy.
